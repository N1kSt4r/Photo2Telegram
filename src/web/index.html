Превью

На диске

Загрузка…

Счётчики страницы и диска независимы: браузер может показать сохранённую миниатюру без обращения к серверу. Поэтому на диске может быть меньше файлов, чем загружено в страницу.

Старые версии превью удаляются автоматически. При достижении лимита удаляются превью, которые дольше всего не запрашивались.

Очистка затрагивает только превью и длительность видео. Оригиналы, посты и подписи сохраняются. Открытые картинки останутся на экране.

Файлы для Bot API

Загрузка…

Подготовленные JPEG и MP4, включая копии очереди. Общие файлы кэша и очереди учитываются по размеру один раз. После очистки неотправленные посты потребуется подготовить заново. Посты, подписи и история отправки сохранятся.

Экспорты в папки

Загрузка…

Копии оригиналов без ресайза и конвертации в папке «Посты для Telegram», вместе с подписями. Удаляются только файлы, перечисленные в экспорте, и его служебные файлы. Исходные фото и видео остаются на месте.

Папка с фото и видео

У каждой папки — свои посты и скрытые файлы. Текущий черновик сохранится перед переключением.

Экспорт постов

Все непустые посты будут сохранены в отдельные папки в исходной директории, включая уже отправленные в Telegram. Оригиналы копируются без конвертации, подписи сохраняются рядом. Текстовые посты содержат только файл подписи.

Настройки сохраняются локально для этой папки. Отправка начнётся только после подготовки и выбора постов.

Подключение канала

Локальный Bot API в Docker

Проверяем Docker…

Управляет контейнером этого проекта на компьютере с Photo2Telegram. Docker должен работать. Ключи можно получить на my.telegram.org → API development tools. Адрес подключения выше сохраняется отдельно.
Ключи сохраняются локально в .env. Пустое поле оставляет сохранённое значение.

Фото готовятся в JPEG с качеством 95, до 2560 px по длинной стороне. Лимит фото: 10 МБ. При необходимости видео преобразуются в MP4 через FFmpeg. Оригиналы сохраняются. Лимит видео: 50 МБ для обычного API, 2000 МБ для локального.
